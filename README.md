# GithubCopilot Cheat Sheet

## 目次

- [エージェントモード](エージェントモード.md)：コードの修正や調査をCopilotに任せたいとき、まず確認するとよい項目です。対話しながら作業を進めたい場面で役立ちます。
- [カスタム命令](カスタム命令.md)：毎回同じ依頼をすることが多いときに使うと便利です。定型の指示や進め方をあらかじめ決めておきたい場面に向いています。
- [カスタムエージェント](カスタムエージェント.md)：役割ごとにCopilotの振る舞いを分けたいときに参照するとよい項目です。特定の作業に合わせた専用の担当を用意したい場合に適しています。
- [SKILLS](SKILLS.md)：決まった作業手順や、特定の操作を素早く再利用したいときに確認すると便利です。作業の型を共有したい場合にも向いています。
